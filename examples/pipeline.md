# Example new pipeline

Create a new pipeline called `Fish Live3 test`; do not modify your preferred one.

| Setting | Example |
| --- | --- |
| Language | English |
| Conversation | Fish Live3 |
| Speech-to-text | Your existing English STT engine |
| Text-to-speech | Fish Live3 Reply Voice |
| Wake word | A model supported by your own satellite |
| Prefer local intents | Off for the conversational test |

Entity IDs are instance-specific; choose them in your own UI rather than copying another home's IDs. First ask a harmless state question. Select this new pipeline on a satellite only after noting its old selection. A Windows PC is not required for the satellite worker.
