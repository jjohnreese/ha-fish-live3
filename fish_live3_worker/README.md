# Fish Live3 Satellite Worker

Private LiveKit audio transport for the HouseTalk / Fish Live3 Home Assistant integration.

Unofficial personal project, unaffiliated with Fish Audio or Home Assistant. Provided as is without warranty or guaranteed support; you are responsible for your own API charges. See the repository's [disclaimer](https://github.com/jjohnreese/ha-fish-live3/blob/main/DISCLAIMER.md) and [cost estimates](https://github.com/jjohnreese/ha-fish-live3/blob/main/docs/pricing.md).

Install the integration first, then install and start this app. Enable start on boot if you use voice satellites. It registers its private Supervisor hostname automatically, including when installed from this GitHub repository.

No Fish API key or custom options are entered here. No LAN port is published. See [setup](DOCS.md), the repository's satellite guide, and security notes before installation.
