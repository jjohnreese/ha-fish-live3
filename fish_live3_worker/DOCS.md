# Setup

1. Install the Fish Live3 custom integration and configure your own Fish key in Home Assistant.
2. Start this app and allow up to 30 seconds for private registration.
3. Create a new English voice-assistant pipeline with Fish Live3 conversation, your existing English STT and Fish Live3 Reply Voice TTS.
4. Select the new pipeline on a satellite for a test. Keep its old selection so you can restore it.

The app's health endpoint returning `ready: false` means its bridge key has not been generated by the integration yet. This is expected if the integration is not configured. Do not publish port 8789 to fix it.

This app has Home Assistant API access and a read-only HA configuration mount for its generated bridge key. Only install trusted app source. It never needs the Fish API key itself. It is not used by the Windows or live dashboard audio path.

Stock satellites take turns and cannot interrupt playback through this bridge. Device firmware controls follow-up listening and its own listening timeout. Abandoned cloud sessions are cleaned up by the integration after inactivity.
